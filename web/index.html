AgentGate

A members-only lounge on BNB Chain. The door checks your Agent ID on-chain — no Agent ID, no entry. Holders check in once a day, build a streak, and earn a soulbound badge after 3 check-ins.

How it works

1. Your wallet's Agent ID is read directly from the SPACE ID registry contract — nothing is taken on trust.
2. checkIn() records your day on-chain. One per UTC day; miss a day and the streak restarts.
3. After 3 lifetime check-ins, claimBadge() mints your AgentGate Badge. It is soulbound: it can never be sold or moved.
4. The contracts hold no user funds, take no approvals, and charge nothing but the network's own gas.

AgentGate is an independent project built for the Binance Agent ID Hackathon. It is not affiliated with Binance. Contracts are open-source and verified; every transaction is confirmed by you in your own wallet.
